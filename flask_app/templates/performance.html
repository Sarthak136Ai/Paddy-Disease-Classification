Model Analysis & Empirical Observations

Evidence-based comparative summary derived strictly from test-set evaluation

Transfer Learning Performance Lift

ResNet50 demonstrated the highest recorded test accuracy (96.93%) and macro F1 score (0.9696) among all evaluated architectures. Pre-trained ImageNet representations provide rich, generalizable feature extractors for microscopic and macroscopic lesion structures on paddy foliage.

Parameter Efficiency & Latency Winner

EfficientNet-B0 achieved the lowest recorded GPU inference latency (7.08 ms/image) while reaching 96.73% test accuracy. With only 4.02M parameters (5.8x fewer parameters than ResNet50's 23.53M), EfficientNet-B0 provides the most balanced trade-off between diagnostic accuracy and low latency for edge or web deployment.

MobileNetV3 & DenseNet121

MobileNetV3 (94.37% accuracy, 4.21M parameters) and DenseNet121 (92.57% accuracy, 6.96M parameters) also exhibited strong transfer learning convergence, though DenseNet's repetitive feature concatenation added slight memory overhead.

Scratch Baseline Limitation

The Custom CNN trained from scratch achieved 45.39% test accuracy and 0.3163 macro F1 score. This substantial difference empirically demonstrates that training directly on 7,284 images without pre-initialized weights is insufficient to fully capture fine-grained paddy leaf pathology patterns.
