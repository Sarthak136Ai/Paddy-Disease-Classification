About & Research Documentation

Paddy/Rice Leaf Disease Detection and Classification Using Deep Learning and Transfer Learning

Project Overview

Research Specification

Rice (Oryza sativa) is a staple food source for more than half the global human population. Pathogenic foliage infections—spanning fungal, bacterial, oomycete, and insect vector damage—cause severe yield loss and economic hardship for smallholder farmers. This project implements a rigorous, reproducible computer vision framework comparing transfer learning representations against a baseline CNN trained from scratch across 10,407 high-resolution field images.

Evaluated Model Architectures

5 Architectures
1. ResNet50 (He et al.)

50-layer deep residual network utilizing identity shortcut connections to solve vanishing gradients in very deep feature hierarchies. Achieved peak test accuracy of 96.93%.

2. EfficientNet-B0 (Tan & Le)

Compound-scaled convolutional network optimizing network depth, width, and image resolution with inverted bottleneck blocks. Achieved 96.73% accuracy at 7.08 ms latency (Recommended production model).

3. MobileNetV3-Large (Howard et al.)

Edge-optimized architecture leveraging hardware-aware Neural Architecture Search (NAS), Hard-Swish non-linearities, and Squeeze-and-Excitation attention modules. Achieved 94.37% accuracy.

4. DenseNet121 (Huang et al.)

Densely connected convolutional network connecting each layer to every subsequent layer in a feed-forward fashion to encourage aggressive feature reuse. Achieved 92.57% accuracy.

5. Custom CNN Baseline (From Scratch)

4-stage convolutional neural network trained without pre-trained weights. Achieved 45.39% accuracy, serving as an empirical baseline proving the indispensable value of transfer learning.

Grad-CAM Visual Explainability (Selvaraju et al.)

Uses target class gradient flow into the final convolutional feature maps to produce a coarse 2D localization heatmap highlighting predictive lesion regions.

Agricultural & Diagnostic Disclaimer

This web application and its underlying deep learning models are developed strictly for academic, research, and educational purposes. Model predictions and Grad-CAM visual attention overlays represent probabilistic statistical patterns and should not be treated as definitive or legal agricultural phytosanitary diagnoses. Field management decisions, chemical spraying, and disease containment should always be verified by certified agronomists or local agricultural extension personnel.
